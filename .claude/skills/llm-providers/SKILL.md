# LLM-фолбэк

Код: `crates/jarvis-core/src/llm.rs` (запросы, ротация, цикл tools), `llm/tools.rs` (схемы инструментов), шаблон настроек `crates/jarvis-core/assets/assistant.default.toml`.

## Как работает

1. `app.rs::ask_llm` вызывается, когда команда не найдена или действие вернуло `ActionError::NotFound`.
2. `complete_with` перебирает провайдеров сверху вниз, модели провайдера по порядку, ключи — по кругу:
   - `429` → ключ на паузу (`Retry-After` или 60 с); `401/402/403` → на час;
   - `400/404/422` → следующая модель (обычно модель не поддерживает tools или устарела);
   - `5xx` → следующая модель; сеть → следующий провайдер, а упавший по сети пропускается 2 минуты.
   - Платный ключ Kilo/OpenRouter из окна настроек — блок `name = "paid"` первым (`sk-or-` → OpenRouter, иначе Kilo); `402` усыпляет ключ на час.
   - Последними — бесплатные модели Kilo без ключа (`KILO_FREE_MODELS`, 200 запросов/час на IP), отключаются `free_fallback = false`; `free_only = true` оставляет только их.
   - Бенчмарк моделей на запросах Джарвиса: скрипт с полным набором tools и 14 фразами (закрой проводник, будильник, напоминание, вкладка, печать, арифметика, факт), латентность медиана/p90; анонимный лимит Kilo — 200 запросов/час, прогонять модели последовательно.
3. До 5 раундов tool calling; опасное действие прерывает цикл вопросом «да или нет».
4. История диалога живёт `memory_minutes`, обрезается так, чтобы начинаться с `user`.

## Отладка

- В `log.txt` пользователя: строки `LLM request: provider=… model=… key#N` и причины отказа. Ключи в лог не пишутся — так и оставить.
- Воспроизводить на Linux мок-сервером (`mock_server` / `queue_server` в тестах `llm.rs`), не реальными ключами.
- Поведение конкретного API (формат `tool_calls`, лимиты бесплатного тарифа) проверять по документации провайдера (WebFetch) и помечать дату: бесплатные тарифы меняются часто.

## Автовыбор модели

`models = ["auto"]` (`llm/models.rs`): `GET {v1beta}/models` с заголовком `x-goog-api-key`, фильтр (без embedding/tts/image/live/exp), порядок: стабильные раньше preview, версии ≥ 3.5 раньше старых, flash-lite → flash → pro, среди версий ≥ 3.5 — младшая (самая дешёвая) первой: 3.5 → 3.6 → …, старые — новее раньше. 429 ставит на паузу пару ключ+модель (`CallError::RateLimit`), поэтому при лимите тот же ключ идёт на следующую модель. Список кешируется на 12 ч; модель, ответившая 400/404, выкидывается из кеша. Нет сети — `GEMINI_FALLBACK`. Gemini сообщает неверный ключ как 400 `API_KEY_INVALID`, блокировку страны — как 400 `location is not supported` (маркер `REGION_BLOCKED`, Джарвис просит включить VPN).

## Добавить провайдера

Любой OpenAI-совместимый `/chat/completions` с `tools`: блок `[[llm.providers]]` в шаблоне (`name`, `base_url` без `/chat/completions`, `models`, `keys`, `keyless` для локальных). Код менять не нужно.
