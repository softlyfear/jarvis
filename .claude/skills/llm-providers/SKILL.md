# LLM-фолбэк

Код: `crates/jarvis-core/src/llm.rs` (запросы, ротация, цикл tools), `llm/tools.rs` (схемы инструментов), шаблон настроек `crates/jarvis-core/assets/assistant.default.toml`.

## Как работает

1. `app.rs::ask_llm` вызывается, когда команда не найдена или действие вернуло `ActionError::NotFound`.
2. `complete_with` перебирает провайдеров сверху вниз, модели провайдера по порядку, ключи — по кругу:
   - `429` → пара ключ+модель на паузу (`Retry-After` или 60 с), `403` → то же на 5 минут; `401/402` → ключ на час;
   - `400/404/422` → следующая модель (обычно модель не поддерживает tools или устарела);
   - `5xx` → следующая модель; сеть → следующий провайдер, а упавший по сети пропускается 2 минуты.
   - Провайдер — только Kilo (`https://api.kilo.ai/api/gateway`). Ключ из окна настроек или установщика — блок `name = "kilo"` первым (`KILO_PAID_MODELS`); `402` усыпляет ключ на час. Старый блок `name = "paid"` при сохранении переименовывается; блоки Gemini старых версий игнорируются и вырезаются из файла.
   - Последними — бесплатные модели Kilo без ключа (`KILO_FREE_MODELS`, 200 запросов/час на IP и с ключом тоже), отключаются `free_fallback = false`; `free_only = true` оставляет только их.
   - Kilo с ключом может отвечать `usage.is_byok = true` и `cost = 0`: к аккаунту подключён свой ключ провайдера, реальная цена — `usage.market_cost`.
   - Бенчмарк моделей на запросах Джарвиса: скрипт с полным набором tools и 16 фразами (закрой проводник, будильник, напоминание, вкладка, печать, арифметика, факт, две искажённые распознаванием), латентность медиана/p90; параллельный прогон многих моделей ловит случайные 403/429 — прогонять последовательно.
3. До 5 раундов tool calling; опасное действие прерывает цикл вопросом «да или нет».
4. История диалога живёт `memory_minutes`, обрезается так, чтобы начинаться с `user`.

## Отладка

- В `log.txt` пользователя: строки `LLM request: provider=… model=… key#N` и причины отказа. Ключи в лог не пишутся — так и оставить.
- Воспроизводить на Linux мок-сервером (`mock_server` / `queue_server` в тестах `llm.rs`), не реальными ключами.
- Поведение конкретного API (формат `tool_calls`, лимиты бесплатного тарифа) проверять по документации провайдера (WebFetch) и помечать дату: бесплатные тарифы меняются часто.

## Добавить провайдера

Основной шлюз — Kilo; модели меняются строкой `models` блока `kilo` (id как на kilo.ai/models). Ещё один OpenAI-совместимый `/chat/completions` с `tools` (например, локальная Ollama) — блок `[[llm.providers]]` (`name`, `base_url` без `/chat/completions`, `models`, `keys`, `keyless`). Блоки с именем `gemini` или адресом Google игнорируются.
