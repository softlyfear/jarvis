# Джарвис — установка и настройка

Голосовой помощник для Windows 11. Говорите «Джарвис», после отклика — команду: «открой телеграм», «запусти доту», «громкость пятьдесят», «удали скриншот с рабочего стола». Всё, чего нет во встроенных командах, понимает нейросеть.

## 1. Установка

1. Скачайте **`JarvisSetup.exe`** со страницы <https://github.com/softlyfear/jarvis/releases/tag/latest>.
2. Запустите его. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**: программа не подписана сертификатом.
3. В установщике:
   - папка — оставьте `C:\Jarvis` (путь должен быть без русских букв);
   - галочка **«Точное распознавание речи и голос Джарвиса»** — для видеокарты NVIDIA; скачивает около 7 ГБ, 20–40 минут, окно установки закроется само;
   - **ключ Gemini** — вставьте ключ (как получить — раздел 3) или оставьте пустым и добавьте позже.
4. В конце нажмите «Завершить» — Джарвис запустится, значок появится в трее у часов. Если выбран не тот микрофон, поменяйте его в **Настройках** (правой кнопкой по значку).

Установщик ставит программу только для текущего пользователя, прав администратора не нужно. Удаление — через «Параметры → Приложения», настройки при этом сохраняются.

Без установщика: скачайте `Jarvis-windows-x64.zip`, распакуйте в `C:\Jarvis`, запустите `jarvis-app.exe`.

Папка настроек — `%APPDATA%\com.priler.jarvis` (`Win+R`, вставить путь, Enter). Внутри:

| Файл | Что это |
|---|---|
| `assistant.toml` | ключи Gemini, голос, названия программ, игр и папок. Открывается из меню Пуск: «Джарвис — ключи и параметры» |
| `log.txt` | журнал Джарвиса: пригодится, если что-то не работает |
| `voice-server.log` | журнал распознавания и голоса |

## 2. Команды без интернета

| Скажите | Что будет |
|---|---|
| «открой / запусти / закрой …» | программа из меню «Пуск», с рабочего стола или из списка в `assistant.toml` |
| «запусти игру …», «поиграем в …» | игра из Steam (находится сама) или ярлык |
| «громче», «тише», «громкость 30», «выключи звук» | звук |
| «пауза», «следующий трек», «предыдущий трек» | музыка и видео |
| «открой загрузки / документы / рабочий стол» | папки |
| «сделай скриншот», «скриншот области», «сверни все окна» | экран |
| «заблокируй компьютер» | блокировка |
| «выключи / перезагрузи компьютер», «спящий режим», «очисти корзину» | переспросит «да или нет» |
| «найди в интернете …» | поиск в Яндексе |
| «какая погода в …» | погода |
| «хватит», «спасибо», «выключись» | закончить разговор, поблагодарить, закрыть Джарвиса |

После команды Джарвис ещё несколько секунд слушает без слова активации, так что команды можно давать подряд.

## 3. Нейросеть: разговор и сложные просьбы

Нужна для всего, что не вошло в таблицу выше: «удали вчерашний скриншот», «какие игры у меня установлены», «сколько будет 15 процентов от 2300», просто поговорить. Работает на бесплатных ключах Google Gemini; из России нужен **включённый VPN** — без него Джарвис так и скажет: «Включите VPN».

1. Откройте <https://aistudio.google.com/apikey> (с VPN), войдите в Google-аккаунт, нажмите **Create API key** и скопируйте ключ (начинается с `AIza`).
2. Вставьте его в установщике или позже: Пуск → «Джарвис — ключи и параметры», строка `keys`:
   ```toml
   keys = ["AIza...первый", "AIza...второй"]
   ```
   Несколько ключей с разных аккаунтов — через запятую: когда у одного кончится бесплатный лимит, Джарвис возьмёт следующий.
3. Сохраните файл и перезапустите Джарвиса: меню в трее → **Перезапустить**.

**Модель выбирается сама** (`models = ["auto"]`): Джарвис спрашивает у Google список доступных моделей и берёт быструю бесплатную (Flash, затем Flash-Lite). Когда Google выпускает новые и убирает старые модели, ничего править не нужно. Если хочется конкретную — `models = ["gemini-2.5-flash", "auto"]`: сначала она, потом автоподбор.

Если нейросеть не отвечает, откройте `log.txt`: там видно, какая модель и с какой ошибкой отказала.

## 4. Голосовой сервер: точное распознавание и голос Джарвиса

Без сервера Джарвис тоже работает: команды распознаёт встроенный Vosk, ответы читает голос Windows. Сервер добавляет две вещи, обе работают на видеокарте:

- **Whisper** — распознаёт речь намного точнее Vosk, особенно названия программ и игр;
- **клон голоса Джарвиса** (XTTS-v2) — ответы нейросети звучат его голосом.

Ставится галочкой в установщике. Если не поставили сразу — запустите установщик ещё раз с галочкой или `C:\Jarvis\tools\voice-server\setup.bat`: он сам скачает Python 3.11, библиотеки (~3 ГБ) и модели (~3,5 ГБ). Джарвис **сам запускает сервер в фоне** при старте, окно держать не нужно; журнал — `voice-server.log` в папке настроек. Установщик сразу включает ответы голосом Джарвиса (`[tts] backend = "http"`).

После запуска сервер загружается 30–60 секунд. В это время команды распознаёт Vosk, потом Джарвис сам переключается на Whisper.

**Видеопамять:** Whisper около 1,5 ГБ, голос 2–4 ГБ. Если в тяжёлых играх не хватает памяти, в `[voice_server]` поставьте `args = ["--no-tts"]` (только распознавание) или `args = ["--whisper-model", "medium"]`. Если видеокарта недоступна, сервер сам переключится на процессор и маленькую модель: медленнее, но работает.

**Свой голос:** положите 10–30 секунд чистой речи в WAV в `tools\voice-server\voice\` и укажите `args = ["--voice", "voice"]`. По умолчанию голос собран из оригинальных фраз Джарвиса.

**Без клона голоса** ответы читает голос Windows (`backend = "sapi"`). Если он английский: Параметры → Время и язык → Речь → Добавить голоса → Русский.

## 5. Автозапуск

Включается галочкой в установщике. Голосовой сервер Джарвис запускает сам.

## 6. Окно с шаром

Пуск → «Джарвис — окно и настройки» (или «Настройки» в меню трея). На главной странице — светящийся шар: дышит в ожидании, прыгает полосками-эквалайзером под ваш голос, крутится фиолетовым, пока думает, и пульсирует оранжевым, когда отвечает.

## 7. Безопасность

- Файлы ищутся и удаляются только в папках из `[safety] allowed_dirs` (по умолчанию Рабочий стол, Загрузки, Документы, Изображения, Музыка, Видео).
- Удаление — всегда в Корзину и только после «да».
- Системные процессы Windows закрыть голосом нельзя.

## 8. Если что-то не так

| Проблема | Что сделать |
|---|---|
| Не реагирует на «Джарвис» | Проверьте микрофон в Настройках (меню трея); говорите чётче, ближе к микрофону |
| «Не нашёл программу» | Добавьте её в `[apps]` в `assistant.toml`: `"как называете" = "C:\\путь\\к\\программе.exe"` |
| Игра не запускается по названию | Добавьте прозвище в `[games]`: `"как называете" = "Точное название в Steam"` |
| «Включите VPN» | Google не обслуживает запросы из России без VPN |
| «Нейросеть сейчас недоступна» | Проверьте ключ Gemini и интернет, посмотрите `log.txt` |
| Не понимает русские команды | Windows на английском: в меню трея → **Язык** выберите «Русский» |
| Английский голос ответа | Установите русский голос Windows (раздел 4) или укажите `sapi_voice = "Irina"` |
| Распознаёт плохо, в `log.txt` нет строк `Whisper` | Голосовой сервер не запущен: откройте `voice-server.log` или запустите `run.bat` вручную и посмотрите ошибку |
| В `voice-server.log` ошибка про `cublas` или `cudnn` | Обновите драйвер NVIDIA; сервер при этом работает на процессоре |
