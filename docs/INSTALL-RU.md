# Джарвис — установка и настройка

Голосовой помощник для Windows 11. Говорите «Джарвис», после отклика — команду: «открой телеграм», «запусти доту», «громкость пятьдесят», «удали скриншот с рабочего стола». Всё, чего нет во встроенных командах, понимает нейросеть.

## 1. Установка

1. Скачайте `Jarvis-windows-x64.zip` со страницы <https://github.com/softlyfear/jarvis/releases/tag/latest>.
2. Распакуйте в папку **без русских букв в пути**, например `C:\Jarvis`. Распознавание речи (Vosk) не открывает модели по путям с кириллицей.
3. Запустите `jarvis-app.exe`. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**: программа не подписана сертификатом.
4. Значок появится в трее у часов. Правой кнопкой по нему открывается меню. Если выбран не тот микрофон, поменяйте его в **Настройках**.

При первом запуске создаётся папка настроек `%APPDATA%\com.priler.jarvis`. Чтобы её открыть, нажмите `Win+R`, вставьте этот путь и нажмите Enter. Внутри:

| Файл | Что это |
|---|---|
| `assistant.toml` | ключи нейросети, голос, названия программ, игр и папок |
| `log.txt` | журнал: пригодится, если что-то не работает |

## 2. Команды без интернета

| Скажите | Что будет |
|---|---|
| «открой / запусти / закрой …» | программа из меню «Пуск», с рабочего стола или из списка в `assistant.toml` |
| «запусти игру …», «поиграем в …» | игра из Steam (находится сама) или ярлык |
| «громче», «тише», «громкость 30», «выключи звук» | звук |
| «пауза», «следующий трек», «предыдущий трек» | музыка и видео |
| «открой загрузки / документы / рабочий стол» | папки |
| «сделай скриншот», «скриншот области», «сверни все окна» | экран |
| «заблокируй компьютер» | блокировка |
| «выключи / перезагрузи компьютер», «спящий режим», «очисти корзину» | переспросит «да или нет» |
| «найди в интернете …» | поиск в Яндексе |
| «какая погода в …» | погода |
| «хватит», «спасибо», «выключись» | закончить разговор, поблагодарить, закрыть Джарвиса |

После команды Джарвис ещё несколько секунд слушает без слова активации, так что команды можно давать подряд.

## 3. Нейросеть: разговор и сложные просьбы

Нужна для всего, что не вошло в таблицу выше: «удали вчерашний скриншот», «какие игры у меня установлены», «сколько будет 15 процентов от 2300», просто поговорить. Работает через бесплатные ключи; из России нужен **включённый VPN**.

1. Получите один или несколько ключей:
   - Google Gemini — <https://aistudio.google.com/apikey>
   - OpenRouter — <https://openrouter.ai/keys>
   - Groq — <https://console.groq.com/keys>
2. Откройте `%APPDATA%\com.priler.jarvis\assistant.toml` в Блокноте и впишите ключи в кавычках:
   ```toml
   [[llm.providers]]
   name = "gemini"
   ...
   keys = ["AIza...первый", "AIza...второй"]
   ```
3. Сохраните файл и перезапустите Джарвиса: меню в трее → **Перезапустить**.

Джарвис перебирает провайдеров сверху вниз, а ключи внутри провайдера — по очереди. Ключ, упёршийся в лимит, пропускается и через некоторое время снова идёт в дело.

Бесплатные тарифы и названия моделей у провайдеров часто меняются. Если нейросеть перестала отвечать, откройте `log.txt`: там видно, какой провайдер и с какой ошибкой отказал. Название модели можно поменять в `models = [...]`.

**Без интернета:** установите [Ollama](https://ollama.com), выполните в терминале `ollama pull qwen2.5:3b` и в `assistant.toml` у провайдера `ollama` поставьте `enabled = true`. Модель займёт около 2 ГБ видеопамяти и отвечает слабее облачных.

## 4. Голос ответов

Короткие реакции («Да, сэр», «Загружаю») звучат записанным голосом Джарвиса. Ответы нейросети озвучиваются одним из способов (`[tts] backend` в `assistant.toml`):

- **`sapi`** (по умолчанию) — встроенный голос Windows. Если он английский: Параметры → Время и язык → Речь → Добавить голоса → Русский.
- **`http`** — клонированный голос Джарвиса на видеокарте:
  1. Установите [Python 3.11](https://www.python.org/downloads/) и при установке отметьте «Add python.exe to PATH».
  2. Запустите `tools\tts-server\setup.bat`. Он скачает около 3 ГБ, это один раз.
  3. Запустите `tools\tts-server\run.bat` и держите окно открытым. Первый запуск скачивает модель (~2 ГБ).
  4. В `assistant.toml` поставьте `backend = "http"` и перезапустите Джарвиса.

  Голос по умолчанию собран из оригинальных фраз Джарвиса. Для своего образца положите 10–30 секунд чистой речи в WAV в `tools\tts-server\voice\` и запускайте `run.bat --voice voice`. Занимает 2–4 ГБ видеопамяти. Если сервер не запущен, Джарвис переключится на голос Windows.

## 5. Автозапуск

`Win+R` → `shell:startup` → положите туда ярлык на `jarvis-app.exe` (и на `tools\tts-server\run.bat`, если нужен клонированный голос).

## 6. Безопасность

- Файлы ищутся и удаляются только в папках из `[safety] allowed_dirs` (по умолчанию Рабочий стол, Загрузки, Документы, Изображения, Музыка, Видео).
- Удаление — всегда в Корзину и только после «да».
- Системные процессы Windows закрыть голосом нельзя.

## 7. Если что-то не так

| Проблема | Что сделать |
|---|---|
| Не реагирует на «Джарвис» | Проверьте микрофон в Настройках (меню трея); говорите чётче, ближе к микрофону |
| «Не нашёл программу» | Добавьте её в `[apps]` в `assistant.toml`: `"как называете" = "C:\\путь\\к\\программе.exe"` |
| Игра не запускается по названию | Добавьте прозвище в `[games]`: `"как называете" = "Точное название в Steam"` |
| «Нейросеть сейчас недоступна» | Включите VPN, проверьте ключи, посмотрите `log.txt` |
| Английский голос ответа | Установите русский голос Windows (раздел 4) или укажите `sapi_voice = "Irina"` |
