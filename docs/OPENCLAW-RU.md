# OpenClaw в Джарвисе

Джарвис умеет работать с нейросетью напрямую или через необязательный OpenClaw Gateway. Микрофон, распознавание, голос Jarvis New, команды Windows и голосовые подтверждения остаются в Джарвисе. Установщик не требует OpenClaw и не меняет его настройки самостоятельно.

## Подключение

Самый короткий путь на Windows:

1. Обновите Джарвиса кнопкой обновления. Установка с нуля не требуется.
2. В «Настройки → Основные → Нейросеть» укажите ключ Polza/Kilo или выберите бесплатные модели, затем выберите OpenClaw.
3. Нажмите «Настроить OpenClaw» и дождитесь результата. При первом запуске скачиваются частные Node 24.16.0 и OpenClaw 2026.9.8; глобальная установка Node не меняется. Архив Node проверяется по SHA256 из официального выпуска.
4. Нажмите «Сохранить». Джарвис перезапустится и будет запускать этот Gateway вместе с собой.

Профиль хранится в `%APPDATA%\com.priler.jarvis\openclaw`. Он использует порт 18790 и случайный токен, отдельно от других установок OpenClaw. Повторная настройка сохраняет токен, память, личные правки persona и внешние MCP. Сохраняйте ключи на вкладке настроек и повторяйте настройку, если нужно перенести новые ключи в профиль. Кнопка «Открыть профиль» открывает `openclaw.json`; секреты из него не отправляйте другим людям.

Встроенные `SOUL.md`, `USER.md`, `MEMORY.md`, `memory/` и два навыка находятся в `openclaw/workspace`. Поиск памяти работает по ключевым словам без отдельного платного embedding API. Индекс обновляется с небольшой задержкой. Основной агент может запускать `jarvis-research` и `jarvis-planner`; помощникам запрещены Windows-инструменты, shell и дальнейшее делегирование. Запись файлов самого OpenClaw ограничена его workspace; остальные файловые действия идут через Джарвис.

Модели профиля обновляются кнопкой «Обновить список моделей». Для импортированных Gemini 3.5 Flash и Flash-Lite указана поддержка изображений; для других моделей добавляйте подтверждённые возможности в их записи `models.providers`. [Flash](https://polza.ai/models/google/gemini-3.5-flash), [Flash-Lite](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite).

Для уже установленного или удалённого OpenClaw остаётся ручное подключение:

1. Установите OpenClaw по [официальной инструкции](https://docs.openclaw.ai/install), настройте модель и создайте отдельного агента `jarvis`.
2. Включите `gateway.http.endpoints.chatCompletions.enabled` в конфигурации OpenClaw. Джарвис использует `/v1/chat/completions`; поле `model` содержит `openclaw/jarvis` и выбирает агента. [HTTP API](https://docs.openclaw.ai/gateway/openai-http-api)
3. В окне Джарвиса откройте «Настройки → Основные → Нейросеть», выберите OpenClaw, укажите адрес Gateway, агента и токен подключения.
4. Нажмите «Проверить подключение». Проверяется авторизованный доступ к списку агентов, а не только открытый порт. Сообщение об успешном подключении не гарантирует наличие денег у провайдера или доступность модели.
5. Сохраните настройки. Если Джарвис уже работает, окно перезапустит его с выбранным режимом.

Токен Gateway отличается от ключа Polza/Kilo. Ввод в окне скрыт; ошибки HTTP не выводят тело ответа и токен. При сборе логов настроенные секреты маскируются. Адрес не должен содержать логин, пароль или параметры с ключом. Для локального подключения используйте HTTP на localhost; для удалённого — HTTPS.

Поле «Модель» можно оставить пустым. Тогда используется модель агента OpenClaw. Чтобы сменить её только для Джарвиса, укажите идентификатор модели, настроенной в OpenClaw. Выбор не привязан к списку провайдеров в Rust.

## Как выполняются просьбы

Встроенная команда исполняется сразу. Фраза, которую команды не обработали, отправляется выбранному агенту. OpenClaw получает сведения о последних локальных действиях: после «открой блокнот» он сможет понять «теперь закрой его».

Обычный ответ приходит в Джарвис и озвучивается F5-TTS. При отсутствии доступного синтеза действует прежнее поведение с текстовым уведомлением. Из ответа исключаются рассуждения, блоки кода, URL и оформление; длина озвучки ограничена.

Вызовы инструментов проходят `tools::to_action` и `Action::run`. Неизвестные инструменты, неверные аргументы, запрещённые папки и системные процессы отклоняются существующим ядром. Модель получает фактический результат действия, включая ошибки. Удаление, питание и очистка корзины ждут голосового «да/нет». Запрос к агенту продолжается после результата подтверждения, а не после одного вопроса.

Произнесите «Джарвис» во время ожидания или озвучки, чтобы прервать ответ. Отмена закрывает текущий HTTP-запрос; актуальный Gateway прекращает свой агентный запрос и соединение с провайдером. Это проверено настоящим Gateway с тестовым провайдером. Уже выполненное действие отмена не откатывает. MCP-вызовы, принятые во время запроса, сохраняют его отмену и после выхода HTTP-потока. Адаптер не получает идентификатор задачи от OpenClaw: новые независимые вызовы после завершения потока и уже отделённые внешние задачи управляются самим Gateway.

## Резервное подключение

«Если OpenClaw недоступен → Использовать прямое подключение» использует прежние настройки Polza/Kilo. Старый конфиг без `[agent]` продолжает работать напрямую.

Автоматический переход допускается, если соединение с Gateway не установилось и локальные инструменты ещё не вызывались. HTTP-ответы 401/404 могут быть ошибками провайдера после начала задачи, поэтому не запускают её повторно через Direct. При таймауте, ошибке сервера либо уже вызванных действиях исходная задача также не повторяется. Джарвис сообщает известные результаты, чтобы не напечатать текст или не записать заметку дважды. Если внутренние MCP-инструменты уже вызывались, а итог Gateway потерян, Джарвис просит проверить результат перед повтором. [Ошибки HTTP API OpenClaw](https://docs.openclaw.ai/gateway/openai-http-api)

## Локальные инструменты MCP

В поставку входит `jarvis-pc.exe`. Это адаптер, который работает через stdin/stdout и отправляет инструменты запущенному `jarvis-app`; второй голосовой движок не запускается.

Включите «Локальные инструменты для внешних агентов (MCP)». При режиме OpenClaw локальный мост включается автоматически. Он слушает случайный порт только на `127.0.0.1`; случайный токен и адрес находятся в `%APPDATA%\com.priler.jarvis\jarvis-pc.json`. Этот файл не попадает в архив логов. Адаптер должен запускаться от того же пользователя Windows, что и Джарвис.

В настройках MCP OpenClaw добавьте сервер `jarvis-pc`, транспорт Stdio, команду — полный путь к `jarvis-pc.exe`. Например:

```powershell
openclaw mcp add jarvis-pc --command 'C:\Program Files\Jarvis\jarvis-pc.exe'
openclaw mcp doctor jarvis-pc --probe
```

OpenClaw хранит определения серверов в `mcp.servers`. [Подключение MCP](https://docs.openclaw.ai/tools/mcp)

Если Gateway работает в WSL, проверьте, что его команда запускает именно Windows-адаптер. Linux-копия ядра не управляет Windows и не использует каталог конфигурации Windows. Наличие записи сервера само по себе не подтверждает работоспособность — нужен probe.

Инструменты имеют имена `jarvis.open_app`, `jarvis.close_app`, `jarvis.type_text`, `jarvis.find_files`, `jarvis.set_timer` и другие из существующего набора. После преобразования имён OpenClaw может показывать собственный префикс сервера; используйте фактический список из probe. Голосовое подтверждение опасного действия происходит в запущенном Джарвисе, и MCP ждёт его результата.

Не давайте агенту два альтернативных способа выполнять одну Windows-операцию. Прямые клиентские Jarvis tools доступны уже через HTTP; MCP нужен для использования инструментов самим OpenClaw и внешними клиентами. В инструкциях агента выберите один путь для конкретной задачи.

## Политика инструментов агента

Проверки Джарвиса защищают вызовы **его** инструментов. Собственный shell OpenClaw или другой файловый MCP могут действовать вне этих проверок. Для агента `jarvis` и его помощников запретите такие обходные пути. Пример ограничения встроенных инструментов для актуальной конфигурации OpenClaw:

```json5
{
  agents: {
    entries: {
      jarvis: {
        tools: {
          deny: ["group:runtime", "group:nodes", "group:ui", "group:automation"],
          fs: { workspaceOnly: true }
        }
      }
    }
  }
}
```

Для каждого подключённого внешнего сервиса задайте разрешённые инструменты отдельно. Проверьте также политику подагентов: запрет должен применяться и к ним. Формат и уровни ограничений описаны в [документации OpenClaw](https://docs.openclaw.ai/tools/multi-agent-sandbox-tools). На старой версии схема может отличаться.

## Память, навыки и внешние сервисы

OpenClaw владеет основной историей беседы. Джарвис сохраняет идентификатор сессии, очередь недоставленных событий локальных команд и незавершённый отчёт об отменённом подтверждении в `agent-session.json`. Копии длинной истории OpenClaw в Джарвисе нет. Direct продолжает использовать свою прежнюю историю.

В созданном профиле память, навыки и ограниченные подагенты уже настроены. Для внешних сервисов нажмите «Настройки OpenClaw в браузере»: откроется Control UI с одноразовым входом, без передачи постоянного токена через журнал или адрес браузера. В Settings → MCP добавьте сервер, задайте URL/stdio-команду, авторизацию и `toolFilter`, затем выполните probe. Сначала подключайте инструменты чтения, например список событий календаря; инструменты отправки и изменения данных включайте только для нужных вам задач. Подключение учётных записей выполняется вами в OpenClaw; Джарвис не знает пароли внешних сервисов. [Подключение MCP](https://docs.openclaw.ai/tools/mcp).

При замене модели сведения о памяти и инструментах остаются ответственностью OpenClaw. Для голоса полезны инструкции: русский язык, мужской род, короткий пригодный для озвучки ответ, подтверждение действий только по фактическим результатам tools. Персона Джарвиса и сведения об активном окне уже передаются из приложения.

Экспериментальный Claude Code CLI подключается встроенным backend `claude-cli` OpenClaw. Нужны отдельно установленный Claude Code и ваш вход в него. Добавьте выбранную модель `claude-cli/<id>` в `agents.defaults.models` профиля, обновите список моделей в Джарвисе и выберите её. Если нужна CLI-модель только как резерв, добавьте её в `agents.defaults.model.fallbacks`. Политика workspace и запреты shell/Windows-обходов должны остаться включёнными: встроенный CLI применяет ограничения OpenClaw к своим нативным инструментам. Подписка Claude, установленный CLI и его авторизация этим выпуском не проверялись. [Официальная настройка CLI backend](https://docs.openclaw.ai/gateway/cli-backends). Hermes не входит в исходный первый этап ТЗ.

## Анализ экрана

Просьба «Что сейчас на экране?» позволяет агенту вызвать `capture_screen_for_agent`. Джарвис делает временный PNG, уменьшает размер до 1600 пикселей по большей стороне, передаёт изображение и удаляет временный файл. Обычная команда «скриншот» по-прежнему сохраняет пользовательский снимок.

Если «Модель для анализа экрана» пустая, изображение получает основная модель агента. Если задана отдельная vision-модель, она получает изображение без клиентских инструментов; описание возвращается основному агенту для дальнейшей работы. Выбранная модель должна поддерживать изображения.

В управляемом профиле отдельный анализ идёт через `jarvis-vision`, которому запрещены все инструменты, включая внутренние MCP. На внешнем Gateway `tool_choice: none` ограничивает только клиентские инструменты HTTP; запреты внутренних инструментов нужно задать в его собственной политике.

Изображения передаются настроенному Gateway и его провайдеру. Их дальнейшее хранение определяется настройками OpenClaw/провайдера; удаление локального временного файла не удаляет серверную копию.

## Дополнительные настройки

```toml
[agent]
backend = "openclaw"
fallback_backend = "direct"
mcp_enabled = true

[agent.openclaw]
base_url = "http://127.0.0.1:18789"
api_key = ""
agent = "jarvis"
model = ""
vision_model = ""
connect_timeout_secs = 3
request_timeout_secs = 60
task_timeout_secs = 300
max_tool_rounds = 32
streaming = false
```

`request_timeout_secs` ограничивает один HTTP-вызов, `task_timeout_secs` — агентную задачу. Ожидание голосового подтверждения имеет прежний отдельный таймаут безопасности; после ответа пользователя бюджет продолжения начинается заново. Долгие задачи не ограничены пятью раундами Direct. Через несколько секунд ожидания Джарвис говорит «Выполняю».

`streaming = true` или переключатель «Готовить голос во время ответа» включает SSE и ранний синтез первого законченного предложения. Предварительный звук используется только при совпадении с проверенным итоговым ответом. Если агент начал tools, сменил backend, вернул ошибку или был отменён, неподходящий фрагмент отбрасывается. Воспроизведение начинается после проверки результата: предварительные рассуждения и обещание успеха не звучат. Если подготовка не успела, ответ озвучивается обычным способом.

## Проверки совместимости

Локальные тесты используют HTTP mock и подмену ОС только там, где реальные действия Windows недоступны. Они проверяют текст, порядок tools, реальные ошибки, подтверждение/отказ, fallback, отсутствие повторов, сессии, изображение, SSE, ограничения, секреты, таймаут и отменённый поздний ответ. Отдельный тест настоящего локального HTTP-моста выполняет безопасный системный запрос и отмену опасного действия через тот же путь, что голосовой цикл.

Для конкретной установки дополнительно проверьте настоящий Gateway и его модель, затем на Windows: «Открой блокнот и напечатай привет», отказ удаления, прерывание ожидания и речи, анализ экрана. Проверка типов Windows и CI не доказывают работу микрофона, GPU, выбранного провайдера и модели OpenClaw.

Настоящий OpenClaw 2026.9.8 автоматически проверяется отдельным CI: авторизация, маршрутизация, SSE, загрузка навыков, запись и поиск памяти, ограничение файлов, делегирование, MCP discovery/filter/call, одноразовый вход в браузере и отмена запроса. Провайдер и MCP-сервис в этом тесте локальные и тестовые; платные модели и реальные аккаунты не используются.

## Приёмка на вашем Windows

1. После обновления проверьте прежние ключи, микрофон и голос. Настройте OpenClaw кнопкой, сохраните и проверьте подключение.
2. «Открой блокнот и напечатай привет». Проверьте фактический текст; следующий запрос «теперь закрой его» должен сохранить контекст.
3. «Запомни: мой любимый цвет — малахитовый». Перезапустите Джарвиса, затем спросите «какой мой любимый цвет?». В workspace должна остаться запись.
4. Попросите составить план сложной задачи с помощником. В Control UI проверьте child session и отсутствие у помощника Windows/shell-инструментов.
5. На тестовом файле попросите удаление, ответьте «нет». Файл должен остаться. Не проверяйте отказ на важных данных.
6. Прервите долгий ответ и звучащую речь словом «Джарвис». Поздний ответ не должен звучать или выполнять следующую Windows-команду.
7. «Что сейчас на экране?» — сравните описание с окном. Для текстовой модели задайте отдельную модель с изображениями.
8. Включите подготовку голоса во время ответа; проверьте F5 и прерывание. Без GPU ожидается текстовое уведомление, а не CPU-синтез.
9. Подключите нужный внешний MCP в Control UI, выполните probe и безопасный запрос чтения. Claude CLI проверяйте только если вы выбрали этот вариант.
10. Повторите настройку OpenClaw и убедитесь, что MEMORY.md, личная persona и внешние серверы сохранились. При проблеме соберите логи: архив включает журналы установки и Gateway с замаскированными ключами.
