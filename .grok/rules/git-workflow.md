# Git для Grok Build

Эти правила относятся только к сессии Grok Build.

- Одна законченная задача — один коммит.
- Типы заголовка: `feat:`, `fix:`, `refactor:`, `chore:`, `docs:`, `test:`
  или `ci:`. Тело — одна-две строки.
- Автор и коммиттер берутся из `git config user.name` и `user.email`.
  Почту ИИ-сервиса не добавлять.
- `--force-with-lease` допустим только по явной просьбе пользователя после
  проверки старого OID.
- Пушить законченную задачу в `master`. После пуша проверить CI по навыку
  `windows-build`.
