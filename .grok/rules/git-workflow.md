# Git для Grok Build

Эти правила относятся только к сессии Grok Build. Файл
`.claude/rules/git-workflow.md` задаёт русский заголовок и атрибуцию Claude
Code. В сессии Grok он не выбирает язык заголовка и не выбирает трейлер.

- Одна законченная задача — один коммит. Незавершённое не коммитить.
- Заголовок — английский Conventional Commit: `feat:`, `fix:`, `refactor:`,
  `chore:`, `docs:`, `test:` или `ci:`. Тело — одна-две строки на английском.
- Автор и коммиттер берутся из `git config user.name` и `user.email`.
  Почту ИИ-сервиса не добавлять.
- Трейлер без почты, если сессия прямо назвала модель:
  `Co-Authored-By: Grok <модель и версия из этой сессии>`.
  Не выдумывать уровень рассуждения и не подставлять пример. Если версия не
  названа, трейлер не писать и прямо сообщить об этом в ответе.
- В индекс попадают только пути задачи. Чужие правки сохранять.
- Опубликованную историю не переписывать и не пушить через `--force`.
  `--force-with-lease` допустим только по явной просьбе пользователя после
  проверки старого OID.
- После зелёных проверок законченной задачи коммитить и пушить `master`,
  как требует корневой `AGENTS.md`. Затем проверить CI по навыку
  `windows-build`.
