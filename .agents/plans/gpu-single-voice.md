# Один голос и синтез только на GPU

Пользователь: удалить CPU-озвучку, оставить Jarvis New (jarvis-remaster), убрать выбор остальных голосов, удалить бывшую вкладку Основные и переименовать Джарвис → Основные. Уменьшить кодовую базу. Коммит/пуш и дождаться CI по правилам проекта.

Решение: F5 ESpeech на CUDA/ROCm, удалить XTTS/coqui и SAPI. CPU/Vulkan остаются только для STT. Записанные звуки Jarvis New воспроизводятся обычным плеером. Без поддерживаемого GPU синтез выключен с явным статусом/ошибкой, не запускается на CPU. Один фиксированный voice ID; исторические voice/app.db и sapi/assistant.toml мигрируют без потери прочих настроек. Удалить старые паки и их доставку через установщик (включая старые папки при обновлении).

Изменения и локальные проверки выполнены: Rust 134, Python 58, frontend test/check/build, Windows cross-check, PowerShell migration/runtime/GPU tests, GUI screenshots (GPU и без GPU). Следующий шаг — коммит, пуш и проверка опубликованного установщика в CI.

Исходное рабочее дерево: только чужой untracked crates/jarvis-gui/gen/schemas/linux-schema.json. Не включать/не удалять.
