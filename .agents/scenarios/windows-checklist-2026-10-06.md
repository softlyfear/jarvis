# Что проверить в Джарвисе после исправлений

Это сценарии для реального Windows-ПК. Исходные ошибки — из испытаний 6 октября на 0.2.69, сборка `7ca05a7`. Прохождение unit-тестов не означает, что нижеприведённые проверки уже пройдены.

## Подготовка и запись результата

Обновить Джарвиса до сборки с исправлениями и записать версию из окна. Создать на рабочем столе отдельную папку «Тест Джарвиса»; положить туда копию PDF `resume.pdf`, текстовый файл и папку с файлом `keep.txt`. Пользоваться тестовыми копиями. Для опыта с Telegram выбрать «Избранное», для терминала — локальное окно, без SSH-сессии.

Каждую проверку начать с указанного состояния. Произносить «Джарвис» перед первой фразой; продолжение без имени проверять отдельно. Не считать ответ «готово» результатом: смотреть окно, путь и содержимое файла. Для первых десяти сценариев сделать по три повтора.

Запись для каждого опыта: **ID / версия / режим / фраза / распознанный текст / что реально произошло / сколько ждал / прошёл или нет**. При сбое записать время с точностью до минуты и собрать логи кнопкой. Полезна короткая запись экрана со звуком. Ключи и личную переписку не присылать.

## Первые проверки: ошибки из новых логов

| ID | Начальное состояние и фраза | Что должно произойти |
| --- | --- | --- |
| R01 | Открыть Блокнот. «Джарвис, закрой» | Джарвис продолжает работать. Закрывает понятный из контекста объект либо уточняет его; не принимает «закрой» за «закройся». |
| R02 | «Джарвис, что за предел действий?» | Отвечает на вопрос. Не читает кнопки активного окна вместо объяснения. |
| R03 | Открыт Steam. «Открой Steam и вкладку библиотека» | Открывается именно библиотека либо звучит честное сообщение о недоступной операции. Ctrl+T и ответ «готово» без перехода — провал. Навигация Steam ещё требует проверки на ПК. |
| R04 | «Открой resume.pdf в папке Тест Джарвиса на рабочем столе» | Открывается нужный PDF в программе просмотра; открытие одного Проводника не считается успехом. Если поиск не понимает папку, повторить с точным путём. |
| R05 | Открыто одно тестовое окно Chrome. «Закрой Google Chrome» | Находит `chrome`, а не отвечает «не нашёл программу». Окно исчезает. |
| R06 | Telegram открыт. «Закрой Телеграм» | После завершения процесса сообщает успех; при незавершённом закрытии не заявляет, что закрыл. Проверить трей и Диспетчер задач. |
| R07 | В тестовой папке лежит непустая «Новая папка» с `keep.txt`. «Переименуй Новую папку в Лучший проект» | Исходного имени больше нет, новое есть, `keep.txt` и его содержимое сохранились. Не предлагает удалять папку. |
| R08 | Уже существуют две папки с разным содержимым. Попросить переименовать первую в имя второй | Отказ без удаления, перезаписи или слияния. Оба набора файлов остаются. |
| R09 | Локальный терминал активен. «Введи echo JARVIS_TEST», затем «Нажми ввод» | Видны отправленный текст и Enter; результат проверяется в терминале. Ответ не должен приписывать этим клавишам создание проекта или подключение к серверу. |
| R10 | Разбить задачу на шаги: открыть Блокнот, напечатать четыре строфы, выделить весь текст, заменить его на две строфы | Проверить начало, конец и переносы строк. Не должны пропадать строки или изменяться другое окно. |
| R11 | «Закрой Obsidian и открой Телеграм» | Выполняет обе части или явно сообщает невыполненную часть; не ограничивается случайной встроенной командой. |
| R12 | Уже открыта тестовая папка. «Создай в ней папки app, core, tests, alembic» | Все четыре папки действительно существуют. При работе через терминал ассистент не объявляет это проверенным результатом только по отправленному вводу. |

R03, работа с содержимым окна, точный выбор одного окна Chrome и создание проектов не считаются полностью исправленными до наблюдения конечного состояния на Windows.

## Окна, редакторы и файлы

| ID | Сценарий | Критерий |
| --- | --- | --- |
| W01 | Открыть Блокнот, Chrome и окно Джарвиса; попросить напечатать текст в Блокноте | Фокус и текст попадают в Блокнот. Настройки Джарвиса и браузер не меняются. |
| W02 | Два окна Chrome. «Закрой только текущее окно Chrome, второе оставь» | Закрывается только одно окно. `close_app` закрывает программу целиком; выбор конкретного окна — отдельная проверка, пока результат не подтверждён. |
| W03 | В Блокноте есть несохранённый текст. «Закрой Блокнот», затем «отмена» | Появляется вопрос о сохранении; после отмены окно и текст остаются. |
| W04 | Повторить W03, ответить «не сохранять» | Закрывается нужное окно; не нажимает «сохранить» и не создаёт файл. |
| W05 | Повторить W03, ответить «сохранить», указать новый путь и имя `jarvis-test.txt` | Файл появился по нужному пути с точным новым текстом. Старый одноимённый файл не считается новым сохранением; диалог «Сохранить как» должен быть завершён. |
| W06 | «Замени содержимое тестового текста на привет мир» | Изменяется содержимое, сам файл остаётся. Запрос удаления файла или Корзины — провал. |
| W07 | Найти отсутствующий PDF и отдельно существующий PDF с пробелами/кириллицей в имени | Для отсутствующего — честный отказ; для существующего — открывается точный файл, путь не теряет пунктуацию. |
| W08 | Два одинаковых имени в разных тестовых папках | Открывает заданный путь либо уточняет выбор. Не выдаёт случайный совпавший файл за нужный. |
| W09 | Попросить открыть или переименовать файл вне разрешённых папок | Отказ. Файл и имя остаются прежними. |
| W10 | В тестовом файле есть уникальная строка. Попросить удалить файл, на подтверждение ответить «нет» | Файл остаётся. Затем отдельно повторить с «да»: файл находится в Корзине. |
| W11 | Chrome уже открыт. «Переключись на Chrome», затем «Разверни мой браузер» | Использует существующее окно; не открывает лишнюю вкладку Яндекса вместо переключения. |
| W12 | Obsidian открыт. «Открой заметку тестовая заметка», затем «Найди в ней слово проверка» | Нужная заметка/поиск действительно открыты либо сообщено ограничение. Открытие папки Документы не заменяет навигацию внутри Obsidian. |

## Речь, память и восстановление

| ID | Сценарий | Критерий |
| --- | --- | --- |
| V01 | Сразу после запуска: «Привет», затем «Открой Блокнот» | Первый ответ и первая команда не теряются. Если сервер ещё загружается, состояние понятно. |
| V02 | За минуту дать пять коротких команд: громкость 30%, громче, тише, выключи звук, включи звук | По одному действию на фразу; проверять системный индикатор и фактический звук. |
| V03 | «Расскажи короткую историю», во время ответа «Джарвис, хватит» | Озвучка прекращается; следующую команду слышит без перезапуска. |
| V04 | Попросить рассказ, в котором есть слово «Джарвис»; самому молчать | Собственный голос не обрывает рассказ и не вызывает новые команды. Проверить отдельно на колонках и в наушниках. |
| V05 | «Прибавь громкость», затем без имени «ещё», затем «а теперь тише» | Продолжения относятся к громкости. После длинной паузы снова требуется активация. |
| V06 | «Какой смысл у жизни?», «Что такое окно в программировании?», «Почему ты сказал готово?» | Обычные вопросы получают ответы; программы, окна и файлы не меняются. |
| V07 | Смешать русские названия с Chrome, Steam, MobaXterm; сказать короткую фразу по-английски | Фразы узнаются достаточно для задачи; ответ остаётся по-русски. Английский ответ из новых логов пока требует повторной проверки качества модели. |
| V08 | Задать простой вопрос, затем вопрос на пару абзацев | Голос без щелчков, обрывов, с понятными ударениями. Записать задержку первого и прогретого ответа отдельно. |
| V09 | Сохранить настройки и перезапустить два раза подряд | Работает один `jarvis-app`, окно подключено, STT/TTS готовы. Нет «порт занят» и зависшего старого сервера. |
| V10 | На время отключить интернет; попросить громкость и открыть Блокнот, затем задать вопрос нейросети | Локальные действия доступны; сеть даёт понятную ошибку с ограниченным ожиданием. После восстановления вопрос снова работает. |
| V11 | Попросить список игр; выбрать установленную; дождаться её окна и попросить закрыть | Проверяется реально появившееся окно, затем его исчезновение. URI запуска не доказывает готовность игры. При UAC на защищённом рабочем столе нужен ручной выбор. |
| V12 | «Запусти игру и сразу закрой её» | При незавершённом запуске сообщает ограничение. Не обещает фонового ожидания, которого нет. Ассистент остаётся доступен. |
| V13 | «Запомни, что тестовую папку называем лабораторией», продолжить разговор и перезапустить в пределах окна памяти | Понимает контекст разговора после перезапуска; не выдаёт такую заметку за изменение настроек или постоянный файловый псевдоним. |
| V14 | Явное «Джарвис, отключись», затем ручной запуск | Завершение выполняется только по явной команде; после запуска ассистент снова доступен. |

## Идеи для следующего этапа

После основных проверок: таймер на минуту и отмена; напоминание с текстом; пауза/следующий трек; поиск YouTube; переключение раскладки; буфер обмена; восстановление закрытой вкладки; сворачивание и возвращение окна; запрос памяти/дисков; скриншот с проверкой нового файла; работа с тихим голосом, шумом и длинной паузой в середине фразы.

Ещё полезны сквозные задачи: «открой файл → измени → сохрани → закрой», «найди игру → запусти → закрой», «открой программу → найди раздел → проверь результат». Проект с `uv` тестировать отдельно в cmd и PowerShell, сначала в папке с простым латинским именем, затем с кириллицей/пробелами. Проверять `pyproject.toml`, имя проекта, структуру и код завершения, а не только отправленную строку. Команды для одной оболочки не обязаны работать в другой.
