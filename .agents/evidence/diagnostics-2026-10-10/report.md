Исправления по свежей сессии версии 0.2.81, сборка e19fc77. Архивная статистика и номера строк — `log-findings.json`, результаты программных проверок — `checks.json` и журналы рядом. Сырые диалоги и ключи не публикуются.

- Google для снимков: пользователь выбрал единственный `gemini-flash-lite-latest`. В запросе `reasoning_effort: low`, до 2048 выходных токенов, таймаут по умолчанию 15 с, максимум 18 с. Переключения на Flash/Pro нет. После ошибки сети/429/недоступности временно пропускаются запросы; числовой Retry-After учитывается. Старое поле `models` игнорируется, ключ сохраняется.
- Окно: отдельный `read_window_text` читает последние 8000 символов видимых TextPattern ranges по прямой просьбе, без отправки снимка Google. `inspect_window` по-прежнему читает кнопки. Данные окна не становятся разрешением запоминать факты.
- Терминал: текстовая область получает фокус; Unicode ввод проверяет активный HWND и делает паузы между символами. Затем проверяется изменение видимого текста и введённая строка в конце. Не подтверждённый ввод запрещает дальнейшие клавиши в запросе, включая Enter. Изменение целевого окна тоже отменяет клавиши. Параллельное чтение stdout/stderr не даёт длинному JSON заблокировать PowerShell; чтение диапазонов сохраняет свежий конец, даже если видимый текст длиннее ограничения. Работоспособность конкретного провайдера UI Automation терминала на Windows ещё требует проверки.
- F5: известные английские имена и короткие аббревиатуры преобразуются в произносимую русскую форму перед RUAccent. Это не меняет аргументы действий, распознанный текст или отображаемый ответ. Слуховая оценка на компьютере пользователя ещё требуется.
- Активация: результат детектора при чтении накопленных кадров теперь учитывается; варианты имени из свежих логов корректно отделяются от команды. Модель остаётся GigaAM Multilingual. По журналу задержка распознавания 67–345 мс, медиана 157 мс; архив не позволяет измерить word error rate без исходного звука.
- Прерывание: используется partial result Vosk, слушатель работает при ожидании синтеза и между предложениями, не выключается для ответа с собственным именем. Отменённые части не возобновляют воспроизведение. Записанные отклики тоже слушаются. Промпт просит не произносить собственное имя; полноценного эхоподавления нет, ложное срабатывание на колонках возможно.
- `native_command` модель не должна вызывать: это техническая запись в истории, а не доступный инструмент. Принудительное завершение программ не добавлялось.
