# Состояние проекта после ревью 01.10.2026

Подробности, оставшиеся вопросы и локальная Windows-проверка: [отчёт](../reviews/2026-09-30.md). Не повторять ревью с нуля при следующем пользовательском отчёте; сопоставлять время, build и выбранные backend с описанными подсистемами.

- Настройки Codex опубликованы в `aeac8d6`; Claude-файлы только для чтения. До работы существовал неотслеживаемый `crates/jarvis-gui/gen/schemas/linux-schema.json`: не включать его в свой коммит автоматически.
- Проверенный Rust-набор: `DOCS_RS=1 cargo test -p jarvis-core --no-default-features --features reqwest,lua,ipc --lib` (117 тестов на момент ревью). IPC выделена в feature, чтобы тестировать настоящий handshake без Vosk/ORT.
- Frontend: `npm test`, `npm run build`, `npm run check`; последний самостоятельно генерирует `.routify`. Исправление собственного `[...404].svelte` нужно сохранить.
- Python: 54 mocked-model tests на 3.12; GPU/model inference не проверялся на реальном оборудовании. PowerShell mock test не завершает реальные процессы.
- Windows app, GUI и CLI cross-check выполняются отдельно. GNU check не заменяет MSVC build, запуск DLL, PowerShell 5.1 и тест установки.
- `storage::atomic_write` — общий механизм замены пользовательских файлов. Он не даёт межпроцессную/многофайловую транзакцию.
- В app/GUI настройки и snapshots всё ещё отдельные: stale overwrite остаётся открытым вопросом. Origin policy также не аутентифицирует native local clients.
- RNNoise тракт исправлен по пользовательским логам 01.10: `rnnoise_stream.rs` согласует 16/48 кГц, сохраняет длину каждого callback и очищает состояние при reset. 125 тестов ядра с feature `nnnoiseless` проходят. Шумодав используется для VAD/gating, распознаватели получают исходный звук; добавлена буферизация 10 мс сверх задержки RNNoise. Проверка реальной записи/микрофона остаётся необходимой.
- Lua hook не прерывает блокирующие Rust API. Full sandbox и доступный `system.open` не являются полной изоляцией недоверенных паков.
- Embedding cache включает id модели/язык/команды, но не digest весов под прежним id. Registry обнаруживает однопоточные циклы, а не перекрёстные циклы между потоками.
- Updater проверяет SHA-256, если поле присутствует; старые metadata без hash допускаются для совместимости. CI новых сборок публикует hash.
- Собственные временные инструменты/логи/кэши находятся в игнорируемых `.codex/.tmp` и `.codex/.cache`. Не переносить их или агентские инструкции в другие папки.
