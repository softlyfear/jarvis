## Проверки и границы

Программная часть готова: Direct/OpenClaw, установка из GUI, управляемый профиль, память, два навыка, два ограниченных помощника, отдельный vision-агент, список моделей, Control UI для внешних MCP, ранний синтез и закрытие HTTP при отмене. Настоящий OpenClaw 2026.9.8 проверен с локальным тестовым провайдером и MCP, включая Rust → Gateway → безопасный нативный Action → фактический tool result.

Приёмка микрофона, GPU/F5, экранного захвата и Windows-действий оставлена пользователю по его указанию. Внешние аккаунты подключаются им в Control UI; Claude CLI требует его установки/входа. Hermes не входит в первый этап. Публикация и итог CI точного SHA приводятся в итоговом ответе.
