## Проверки и границы

Все восемь частей реализованы в коде. Сценарии настоящего Windows/Gateway проверяются на ПК после установки; в этой Linux-среде проверены HTTP mock, реальный локальный MCP-мост, интерфейс и Windows types. Память, навыки, внешние сервисы и подагенты настраиваются в OpenClaw; ранняя потоковая озвучка остаётся следующим необязательным шагом исходного ТЗ.
