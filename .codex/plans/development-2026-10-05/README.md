# Три последовательные задачи

1. **Качество разработки.** Независимый reviewer, сценарии из логов 5 октября, навыки анализа логов/сравнения голоса, проверяемое закрытие требований.
2. **MCP.** Выбрать полезные серверы, разместить конфигурацию и кеши внутри `.codex/`, проверить настоящий handshake и рабочие инструменты. Сохранить имеющиеся подключения.
3. **Модели речи.** Тщательный поиск через подключённый Hugging Face, чтение карточек и первичных источников, сравнение русского языка, клона голоса, задержки и Windows/CUDA/ROCm. Подготовить измеримый следующий шаг.

Задачи выполняются по порядку. Критерии и доказательства хранятся в `requirements.json`; проверка: `python3 .codex/tools/check_evidence.py .codex/plans/development-2026-10-05/requirements.json`.

Сценарии известных ошибок проверяют качество инструментов контроля. Добавление сценария не означает исправления ошибки приложения. Настоящие результаты на Windows и GPU учитываются отдельно от фикстур.
