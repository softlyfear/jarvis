Архив jarvis-logs-1791921516.zip: свежие сессии 0.2.82, сборка ad391eb; не результат проверки новой версии.

Google возвращал описание за 1,9–4,4 с. Последующий обрыв происходил по событию wake, а не по отсутствию ответа Google. В двух описаниях своего окна было JARVIS. Пользователь подтвердил звук через колонки; акустическое эхо вероятно, но без WAV не доказано.

Изменения: краткая причина ошибки без формальной подводки; разные отказы и подтверждённые успехи сохраняются. Собственное wake-имя заменяется только перед синтезом речи при включённом barge_in. Partial wake требует 200 мс устойчивого совпадения по аудиосэмплам, finalized wake прерывает сразу. Полного AEC нет; собственный голос на колонках всё ещё может давать ложные finalized/stable распознавания.

Удалённый HTTP-пул пересоздаётся после transport failure. Generation защищает восстановленный пул от поздних старых workers. Сетевой отдых 3 с; HTTP-квоты/ключи сохраняют прежние сроки. Уже полученный статус отказа сохраняется при обрыве тела; поздняя сетевая ошибка не сокращает защищённый cooldown. Упал запрос — автоматического повтора POST нет; следующий пользовательский запрос новый. Ротация других провайдеров сохранена.
