Запусти `python3 .codex/tools/review_logs.py ARCHIVE --output .codex/.tmp/log-review.json` из корня проекта. Для конкретного дня добавь `--date YYYY-MM-DD`, для версии — `--version 0.2.N`. Скрипт не распаковывает архив на диск и выдаёт только разрешённые поля.

Сначала установи версию, сборку и режим агента. Отделяй сессии по запуску приложения; ошибки старых версий не приписывай новой. Сверь последний сбой с последующими успешными запросами и кодом исполнения.

Для каждой находки сохраняй фразу, время/строку, наблюдаемое действие, ожидаемый результат, степень уверенности и критерий исправления. Не объявляй нажатие клавиши доказательством сохранения, найденный ранее файл — новым результатом, а заметку пользователя — изменением настроек. Без аудио/экрана не устанавливай ложные активации и содержимое окна.

Секреты и полные диалоги не коммить. Вывод анализатора тоже проверяй перед публикацией. Запросы LLM/сети не выполняй ради воспроизведения архивного сбоя. Сценарии и их формат описаны в `.codex/scenarios/README.md`. Пункт ТЗ закрывай по правилам `.codex/AGENTS.md` и `check_evidence.py`.
