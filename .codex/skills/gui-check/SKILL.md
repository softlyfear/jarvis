# Проверка окна настроек

Окно — Tauri 2 + Svelte (`frontend/`). Под Linux его не запустить целиком, но фронтенд рендерится в Chromium: `scripts/shoot.py` поднимает `vite`, подменяет `window.__TAURI_INTERNALS__` (как `mockIPC` из `@tauri-apps/api/mocks`) и WebSocket к jarvis-app, снимает страницы и печатает ошибки консоли и вызванные команды Tauri. Скриншот после правки — обязательная часть проверки: `svelte-check` не видит съехавшую вёрстку и пустой шар.

## Запуск

```bash
# Из корня репозитория; все служебные файлы остаются в .codex/.
mkdir -p "$PWD/.codex/.tmp"
export TMPDIR="$PWD/.codex/.tmp"
export UV_CACHE_DIR="$PWD/.codex/.cache/uv"
export PLAYWRIGHT_BROWSERS_PATH="$PWD/.codex/.cache/playwright"
export PYTHONDONTWRITEBYTECODE=1
uv run --no-project --with playwright python .codex/skills/gui-check/scripts/shoot.py
# только главная, шар в состоянии «говорит»
... shoot.py --routes / --state speaking
# свои ответы команд: {"assistant_settings_read": {...}, "voice_server_status": {...}}
... shoot.py --fixtures .codex/.tmp/gui/fixtures.json
```

- `--state off|idle|listening|speaking` — jarvis-app не запущен / ждёт / слушает / говорит (фейковые `audio_level` ~30/с с 16 полосами, как `visual.rs`).
- Размер по умолчанию — окно из `tauri.conf.json` (550×800).
- Код выхода 1, если страница написала ошибку в консоль. Скриншоты открыть инструментом просмотра изображений Codex (`view_image`, если доступен).
- Нет браузера: `uv run --no-project --with playwright python -m playwright install chromium`.
- `npm ci --cache ../.codex/.cache/npm` в `frontend/`, если нет `node_modules`.
- Скриншоты по умолчанию — `.codex/.tmp/gui/`. `--out` и JSON-фикстуры допускаются только внутри `.codex/`. Настройки кешей выше действуют и при установке Chromium.

## Новая команда Tauri

Неизвестные команды получают `null`. Если страница падает на `Cannot read properties of null` — добавить ответ в `FIXTURES` скрипта по реальной структуре из `crates/jarvis-gui/src/tauri_commands/` (serde-поля как в Rust). Переводы берутся из `crates/jarvis-core/src/i18n/locales/ru.ftl`.

## Что скрипт не проверяет

Нативное окно Tauri, трей, диалоги файлов, реальные `invoke` в Rust, звук. Это — CI и реальный ПК; не выдавать за проверенное.

## Дизайн

У окна уже есть свой стиль (тёмный фон, шар-реактор, зелёные акценты настроек): правки продолжают его, а не вводят новый.

- Один выразительный элемент на экран — шар на главной. Вокруг — спокойно: не добавлять градиенты, тени и анимации «для красоты».
- Движение — только в ответ на действие или состояние (слушает, говорит, загрузка). Уважать `prefers-reduced-motion`.
- Структура несёт смысл: нумерация — только для настоящих шагов, разделители и подписи — только если различают содержимое.
- Окно узкое (550 px): проверять, что длинные русские строки переносятся, а не обрезаются, и кнопки не вылезают.
- Видимый фокус с клавиатуры, достаточный контраст текста на тёмном фоне.

## Тексты интерфейса (русский)

- Писать для пользователя, а не про устройство программы: «Голос ответов», а не «TTS backend».
- Кнопка говорит, что произойдёт: «Сохранить», «Собрать логи для отправки». Одно действие — одно слово по всему пути: кнопка «Проверить обновления» → статус «Проверяю обновления…».
- Ошибка — что случилось и что сделать, без извинений и общих слов: «Голосовой сервер не отвечает. Перезапустите Джарвиса или переустановите сервер».
- Пустое состояние подсказывает следующий шаг.
- Предложения обычным регистром, без лишних слов; каждый текст делает одну работу.
